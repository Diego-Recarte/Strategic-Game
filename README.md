Ejecucion:
1. Abre el proyecto en NetBeans.
2. Verifica que las imágenes se encuentren dentro de la carpeta de imagenes`.
3. Ejecuta el proyecto.
4. Crea una cuenta o inicia sesión.
5. Selecciona los jugadores y comienza la partida.


Durante un turno se debe :

- Detener la ruleta.
Seguido de 
- Mover personaje
- Atacar a un personaje rival
- Utilizar una habilidad especial.
tambien
- Consultar las opciones de la partida.
- Retirarse.
